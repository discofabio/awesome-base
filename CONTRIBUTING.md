# Contributing to Awesome Base

Thank you for your interest in contributing! 🎉

## How to Contribute

1. **Fork** this repository
2. **Add** your resource to the appropriate category in `README.md`
3. **Follow** the format: `- [Name](URL) — Short description.`
4. **Commit** with a clear message: `add [resource name] to [category]`
5. **Open** a Pull Request

## Guidelines

- The resource must be related to the **Base ecosystem**
- Use the following format: `- [Resource Name](https://example) — Short description ending with period.`
- Keep descriptions concise (under 100 characters)
- Check that the link is working before submitting
- Add the resource to the **most relevant** category
- Don't add duplicates
- One resource per pull request (preferred)

## Categories

If your resource doesn't fit an existing category, suggest a new one in your PR.

## Quality Standards

Resources should be:
- ✅ Actively maintained (for tools/projects)
- ✅ Relevant to Base builders
- ✅ Well-documented
- ❌ Not scams, phishing, or malicious
- ❌ Not purely promotional without substance

## Reporting Issues

- Broken links → Open an issue with the resource name
- Outdated info → Open an issue or PR with corrections
- New category suggestion → Open an issue to discuss

Thank you for helping make this list awesome! 🚀
